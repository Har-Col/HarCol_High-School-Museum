# 高中生活博物馆
《高中生活博物馆》是我用codex接入DeepSeek api制作的一款轻量化纯静态纪念网页，基于 HTML、CSS、JavaScript 开发，部署于 GitHub Pages。
项目以博物馆存档为核心创意，记录高中日常碎片、专属回忆

https://har-col.github.io/HarCol_High-School-Museum/


## ⚙️小功能
-成就系统
-图片景深效果
-鼠标跟随聚光灯
-隧道光转场特效（亲自调试！）

## ❓️其他
数据本地保存，不可跨设备保存数据
需要重新观展的可以在顶部栏→目录→最底部的重置观展进度来重新体验
